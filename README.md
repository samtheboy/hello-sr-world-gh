# Task Manager

A full-stack Task Manager application built as a hands-on CI/CD learning project.

## Technology Stack

- **Backend:** Java 21, Spring Boot
- **Frontend:** React
- **Database:** PostgreSQL
- **Version Control:** Git and GitHub
- **CI/CD:** GitHub Actions
- **Containerization:** Docker

## Project Goals

- Build a full-stack application.
- Learn Git branches and Pull Requests.
- Automate builds and tests using GitHub Actions.
- Containerize the application using Docker.
- Deploy the application to a Linux server.
